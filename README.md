# Hoàng Lê Khoa — Fresher Web Developer Portfolio

Website portfolio và ba sản phẩm demo (HTML/CSS/JavaScript thuần):

1. **Personal Portfolio** — `index.html` (trang giới thiệu).
2. **Quản lý sinh viên** — `student-manager.html`, CRUD và tìm kiếm, lưu bằng localStorage.
3. **Cloud Computing Notes** — `cloud-notes.html`, 6 bài học, tìm kiếm và lưu tiến độ.

**Website:** https://TobiOrigami.github.io/hoang-le-khoa-portfolio/

Các chức năng chạy phía trình duyệt, không cần cài đặt hay backend. Dữ liệu localStorage chỉ nằm trong trình duyệt và có thể bị xóa khi xóa dữ liệu trang web. Các dự án này phục vụ mục đích học tập và trình diễn.
