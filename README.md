# Portfolio Hoàng Lê Khoa — 3 dự án demo chạy được

Mở `index.html` bằng trình duyệt. Trong mục **Dự án tiêu biểu**, chọn:

1. **Personal Portfolio** → `index.html` (trang chính).
2. **Quản lý sinh viên** → `student-manager.html` (thêm/sửa/xóa/tìm kiếm, localStorage).
3. **Cloud Computing Notes** → `cloud-notes.html` (6 bài học, tìm kiếm, đánh dấu hoàn thành, localStorage).

Tất cả chạy offline không cần backend. Dữ liệu chỉ lưu trên trình duyệt và thiết bị hiện tại; xóa dữ liệu trình duyệt sẽ mất dữ liệu. Đây là sản phẩm thực hành, không phải ứng dụng doanh nghiệp. Có thể đăng cả thư mục lên GitHub Pages/Netlify/Vercel để chia sẻ link.
